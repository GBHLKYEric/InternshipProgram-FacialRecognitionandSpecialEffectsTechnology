官方资料、论文与许可核验

核验日期：2026-09-26。资料中的基准数字是作者的实验结果，不是本项目测量值。所有可变的软件版本以本机环境报告为准；网页使用滚动的 main/stable 时，复现实验应另记录提交号或安装版本。

原需求中需要校正的事实

  • OpenMMLab 不应写成“字节跳动开源项目”。其官方介绍及教程列出的机构包括香港中文大学、商汤等；本项目应写“使用 OpenMMLab 开源视觉框架”。没有证据支持原 PDF 对字节内部使用范围的陈述。OpenMMLab 官方教程
  • BytePS 是实际存在的开源分布式训练框架。官方仓库于 2025-12-08 归档，其说明要求 CUDA/NCCL，明确不支持纯 CPU 训练。一个单进程梯度平均示例只能叫原理模拟。BytePS 官方仓库
  • ByteNN（模拟）不可写成已经安装了字节内部引擎。本次未获得可核验的官方公开 SDK、授权或运行接口；ONNX Runtime 可以演示跨平台推理原理，但不等于 ByteNN。字节跳动官方开源组织
  • MMClassification 的后续项目为 MMPreTrain。学习旧文档时应留意工程名称与版本，而不要把新旧配置混装。MMPreTrain 官方仓库

环境与工程

资料 本项目用来核验的内容
MMDetection 3.3.0 版本断言 2.0.0rc4 <= mmcv < 2.2.0，0.7.1 <= mmengine < 1.0.0。并不是任意最新版本都兼容。
MMDetection 安装 Python、PyTorch、MMCV、MMEngine 的安装顺序及推理流程。
MMCV 安装 wheel 必须匹配操作系统、Python、PyTorch、CUDA；下载 .tar.gz 表示可能进入源码编译。mmcv-lite 不提供全部编译算子。
PyTorch 量化 动态/静态/QAT 的区别；旧 eager API 与新量化工具的迁移，需与安装版本对应。
PyTorch ONNX 导出 导出器、算子集与动态形状；转换后必须运行数值一致性检查。
OpenCV YuNet 模型说明 轻量人脸检测与五点定位；模型目录的单独许可证。
OpenCV SFace 模型说明 特征提取、对齐与相似度；模型说明中的 Apache-2.0 声明。
SFace 权重溯源待澄清 issue 2026-09-26 核验时仍有关于准确权重训练数据来源的未答问题；本项目不额外保证一切商业用途。
InsightFace 官方许可 代码 MIT 与公开预训练模型的非商业研究许可分别处理；不把“开源代码”解释为“权重无限制”。
PyTorch3D 安装 PyTorch/CUDA/C++ 扩展匹配，不能假设任意 Windows wheel 都存在。

数据集 官方/维护方来源 获取与使用边界
CelebA 香港中文大学项目页；torchvision 下载器 项目页列出 202,599 张、10,177 个身份、40 属性、5 关键点。非商业研究，禁止再分发图像与数据；身份标注说明有研究申请条件。只在本地存储合法获取的数据，开源仓库发布加载器。
LFW 原站；scikit-learn 官方下载器与 SHA256 原站本次网页工具不可达；维护方下载器提供 Figshare 原图与 pairs 镜像。13,233 图、5,749 身份；评估必须说明原图/对齐版、检测失败与十折协议。
MS-Celeb-1M 微软研究历史项目页；原始论文 历史页保留 2016 年竞赛说明，不是本次有效下载/授权凭证。本项目没有获得可核验的授权训练包，不从未知镜像补齐。若用合法自建身份数据，必须在报告写成替代数据实验。
WIDER FACE 作者论文；作者项目页；torchvision 官方下载器 原站本次网页工具不可达；维护方下载器保留 Google Drive 入口。需训练图、标注与独立验证图；不能把几张演示图的 AP 写成 WIDER 全集 mAP。
300-W Imperial College iBUG 官方页 研究用途、禁止商业训练；68 点，原标注从 1 开始计数；评估 NME 使用外眼角距离。官方页中的 600 张 challenge test 与常见训练集不是同一个拆分，必须记清。
COFW 作者论文页面 可替代 300-W 的研究方向；标注数量和遮挡处理必须依具体协议，不能混用 300-W 的 68 点指标。

必读论文与扩展阅读

  1. RetinaFace: Single-stage Dense Face Localisation in the Wild：检测、五点与多任务监督；读“输出是什么、多个任务如何共同训练”。
  2. ArcFace: Additive Angular Margin Loss for Deep Face Recognition：把类别分离转换到归一化特征的角度空间；注意论文发表年份与预印本年份不同。
  3. StyleGAN3 / Alias-Free GANs；NVIDIA 官方实现：减少纹理黏在图像坐标上的现象；使用旧 StyleGAN2 权重并不会自动得到 StyleGAN3 效果。
  4. DECA：从野外图像估计可动画化的详细三维人脸。
  5. StarGAN 官方实现：多个属性域共享生成器与判别器。
  6. PRNet 官方实现：位置图回归的三维重建。3DDFA_V2 官方实现：三维稠密对齐。模型、基底数据与代码许可需要分别看。
  7. DDPM：逐步加噪与学习去噪。NeRF：从视图学习空间密度和颜色。3D Gaussian Splatting：用可优化三维高斯表示和渲染场景。
  8. FID 的原始论文 TTUR：比较特征分布；图像少、特征器不同或预处理不同的分数不可直接比较。
  9. HRNet：保留高分辨率与跨尺度融合。SAN：用风格聚合减少输入风格变化对关键点检测的影响。AttGAN：属性约束与保留非目标内容的生成研究。
  10. Khronos WebGL 官方说明：WebGL基于OpenGL ES，使用浏览器图形接口；生成查看器HTML不等于已在目标GPU/浏览器渲染验收。
