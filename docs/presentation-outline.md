# 项目汇报逐页大纲

此大纲由实际PPT内容同步生成；数字的完整协议与限制见项目报告。

## 1. 人脸视觉 从原理到可运行系统

- 本地 CPU 应用 · 训练与评估管线 · 3D 重建
- 面向高三学生的可复现学习项目
- 独立教育项目，与字节跳动无隶属关系


## 2. 范围与验收口径

- PDF 含环境、检测、关键点、识别、优化、GAN、3D 与动态特效
- 预训练推理、代码冒烟测试、真实数据实验是三种不同证据
- 98.5% 是目标，必须由完整协议的实测报告支持


## 3. 系统如何处理一张图像

- 图像 → YuNet 检测框与五点 → 对齐 → SFace 特征 → 余弦比较
- 关键点 → 几何变换 → 眼镜、皇冠、美颜、美妆
- 最终为原生 Tk 桌面窗口；OpenCV 直接读取相机，图像留在内存


## 4. 真实原生桌面界面

- 直接启动本机窗口，六种显示模式；图片与摄像头输入
- 后台线程读取/推理，主线程更新 Tk 窗口
- 停止、重开和退出释放摄像头已实测

配图：`reports/desktop-window.png`。


## 5. 环境与可重复性

- Windows 11 · Core Ultra 5 225H · 32 GiB RAM · Intel Arc 130T
- Anaconda 2026.07-1 / conda 26.5.3；项目 Python 3.12.14
- 主 venv、conda、XPU 和 MMDetection Docker 分开验证


## 6. 人脸识别与 ArcFace

- 对齐后的人脸 → ResNet50 → L2 归一化特征
- ArcFace 训练正类 logit：s cos(θ + m)，使类间更易区分
- P-K 采样与 batch-hard triplet 辅助；实测反向传播及保存重读


## 7. 真实训练：结果尚未达到目标

- 52 个身份 / 133 张训练图；3 epochs；测试身份名无交集
- 平均训练损失：40.112 → 36.925 → 36.126
- 自训 FP32 完整 LFW：52.6667%；小数据短训未收敛


## 8. LFW 的真实验证结果

- 完整 6,000 对 / 10 折；准确率 98.93%
- 阈值仅由其余训练折确定；测试折不选阈值
- 预训练 SFace 基线；不能归属于本项目从零训练的 ResNet50


## 9. 一次失败怎样变成有效实验

- 首轮严格单脸策略：72.25%；全部失败都来自多脸图
- 原图包含背景人脸；应用验证与数据集主体选择规则不同
- 保留失败报告，按最大主体规则独立重跑；不删除困难样本

配图：`reports/lfw-detection-audit.jpg`。
